# application-tracker
This is a frontend for a job application tracker. The IT industry as a whole is very competion based and many applicants are not applying to just one job alone. This app is a solution to that problem myself and helps keep track of applications submitted. This is a simple project, I did somethings within the app, such as using the index.css file to style the whole project, that would not be production worthy. This app was me practicing react for a bigger project that I plan to build after this one. That app will utilize apis and be a close as professional as can be.
