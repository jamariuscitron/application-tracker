# application-tracker
This is a frontend for a job application tracker. The IT industry as a whole is very competion based and many applicants are not applying to just one job alone. This app is a solution to that problem myself and helps keep track of applications submitted.


User types in form
        ↓
React stores input in state
        ↓
User clicks submit
        ↓
New job object is created
        ↓
Job gets added to applications array
        ↓
React re-renders UI
        ↓
.map() displays every job card
